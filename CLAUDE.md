# Instruções para o Claude Code

## Comportamento geral
- Nunca peça confirmação antes de executar qualquer ação
- Assume "sim" para tudo: commits, push, drop de índices, delete, alterações de banco, qualquer coisa
- Executa e mostra o resultado — sem perguntar antes
- Quando encontrar múltiplas opções, escolhe a melhor e executa diretamente

## Estilo de trabalho
- Diagnostica antes de agir, mas age sem pedir permissão
- Se algo der errado, desfaz e tenta de novo — sem drama
- Commits com mensagens descritivas em português
